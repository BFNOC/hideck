# MCP 能力检查

检查日期：2026-10-25。范围为 MCP 工具目录、现有业务接口、网页接入、配置生成和验证记录；不是全仓库安全审计。

现有 125 个显式工具覆盖设备、网络、SIM/MBN、eSIM、短信、联系人、电话、代理、命令、余额、自动任务和诊断。没有把 REST 别名、网页媒体租约接口、文件上传的不同传输格式计为缺失工具。

## 本次处理

- 增加 Grok Build 配置与复制说明，使用其原生 HTTP MCP 和 `headers`，保留其他七种客户端的配置格式。Grok Build 1.0.67 已实际连接 179 的 HTTP 和 HTTPS，完成握手并发现 125 个工具；HTTPS 验证本地 CA，测试记录已删除。
- 精简网页介绍、字段说明、客户端提示和删除提示；保留名称必填、完整业务权限、令牌仅显示一次和网页音频授权等必要信息。详细安装与验证步骤仍在「复制给 Agent」内容和接入文档中。
- 将令牌弹窗挂载到 `body`，避免系统设置区块的 `transform` 动画和外层裁剪限制固定遮罩。依据为 `Settings.vue` 的区块动画及 Element Plus 的默认非传送弹窗实现；不改变令牌业务流程。
- 后续已补齐 125 项工具的输出契约、服务端调用说明和网页接入诊断。现有响应字段保持一致；旧接口未细化的业务数据仍明确保留通用结构，不声称全部硬件字段均已建立完整类型。接入记录仅保留本次进程的真实元数据，未改变令牌权限或增加硬件操作。

## 已确认缺口与优化优先级

| 优先级 | 类型 | 现状、影响与建议 |
| --- | --- | --- |
| 高 | 功能缺口：Ut/XCAP 呼叫设置 | `internal/api/ut.go` 已有 `/devices/:device_id/ut/simservs` 查询与修改，包含呼叫转移、主叫号码隐藏、呼入和呼出限制；`mcp_catalog.go` 没有对应工具。建议提取共享用例后提供查询和修改工具，保留 ETag 并发校验、单次只修改一个服务及当前设备可用性检查。不能仅给任意 AT 工具增加说明来替代这些业务能力。 |
| 高 | 验证缺口：真实客户端与硬件 | 已实际连接官方 SDK 和 Grok Build，其他原生客户端仍以配置语法及网页交互验证为主。短信实际发送/投递、eSIM 下载/切换和网页双向音频仍未完成真机验收。应按 `mcp-validation.md` 分项记录，避免把模板支持当作完整客户端或硬件验收。 |
| 中 | 功能增强：事件消费 | 网页已有 `sms_events.go`、电话事件和命令事件接口；MCP 当前只提供查询与请求内进度，录音资源没有事件订阅。常驻 Agent 需要主动轮询才能发现新短信或来电。建议先明确事件游标、补发与等待的共享用例；若提供 MCP 原生推送，需要同时评估当前无状态传输、客户端订阅支持和重连生命周期。 |
| 已处理 | 输出结构与使用说明 | 全部工具注册 `outputSchema`；服务端 `instructions` 和关键工具描述说明标识符、分页、异步状态及失败处理，补充命令/MBN 等结构。已有字段和错误保留；成功结果按输出契约校验，不自动重试写操作。其余未细化的旧业务响应仍可逐步补充字段模型。 |
| 已处理 | 接入诊断 | 新增网页登录鉴权的 `/api/mcp/diagnostics` 和「检查接入」，区分服务就绪、鉴权请求与工具调用；按令牌展示内存中的最近请求、工具名、耗时和失败标记。重启、撤销或删除后清除，不包含业务参数、结果或令牌明文。客户端网络/TLS 仍以实际连接结果为准。 |

OAuth、设备权限矩阵、系统升级/卸载、网页登录凭据和通知密钥配置是原计划明确排除的范围，不算本次发现的遗漏。实时语音模型也不包含在网页音频授权能力中。
