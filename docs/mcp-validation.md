# MCP 验证与真机验收

验证日期：2026-10-25。软件验证在 macOS、Go 1.26.4 的本地工作区完成。尚未完成下表列出的真机验收，不能据此宣称完整硬件验收通过。

## 已执行的软件验证

| 范围 | 结果与证据 |
| --- | --- |
| SDK 协议 | 官方 SDK 客户端建立 Streamable HTTP 连接，发现工具和录音资源模板，实际调用工具、接收 progress 通知、读取资源；允许无参数调用省略 `arguments`，必需参数仍验证；125 项工具使用显式目录注册 |
| 输出契约和调用说明 | SDK 发现全部 125 项工具的输出 Schema，均可解析；初始化收到工作流及鉴权错误说明，引用的工具名均在目录中。实际联系人写入/查询/导出/删除、网页连接查询、参数及业务失败结果符合契约，文本与结构化 JSON 一致。覆盖 nullable、录音路径字段移除、本地 Schema 引用、无法解析的契约初始化失败，以及输出不符合契约时明确失败且不重复执行 |
| 接入诊断 | `/api/mcp/diagnostics` 仅接受网页会话并禁用缓存，MCP 令牌与未登录请求被拒绝；区分协议发现和实际工具调用，记录成功及失败状态。覆盖服务关闭、无有效令牌、存储读取和工具初始化失败，诊断不含令牌、摘要、媒体租约或业务参数；快照不共享可变指针，撤销/删除清除记录，进行中的调用结束不会恢复已删除记录 |
| 版本兼容 | SDK 实际处理 `2025-03-26`、`2025-11-25` 请求；未自行实现 JSON-RPC |
| 鉴权 | 无令牌、错误令牌、网页会话令牌、已撤销令牌被 MCP 拒绝；MCP 令牌被网页 API 拒绝；关闭服务与跨源请求被拒绝 |
| 存储 | SQLite 仅持久化摘要及元数据；序列化不含明文和摘要；重新建立令牌服务后仍能鉴权、独立撤销；开关写入配置并能重新加载 |
| 令牌删除 | SQLite 验证有效及已撤销令牌可永久删除，旧令牌鉴权失败，其他记录不受影响；删除接口仅接受网页会话，缺失记录返回 404，存储失败保留记录及音频授权；并发绑定与删除共用现有互斥锁，删除后不残留绑定 |
| 真实业务链路 | 联系人实际写入 SQLite 后可从 REST 读取，删除和文件导入实际提交；大写 VCF 文件名可用，宿主机路径被拒绝 |
| 短信失败 | SDK 调用离线设备、旧 ICCID、额度耗尽和注入发送器失败均返回错误；保留限额错误码、等待秒数和发送失败原因；失败发送只执行一次，未实际发送短信 |
| 并发 | REST 与 MCP 共同等待现有 eSIM 变更锁；撤销令牌与音频绑定交错时不残留授权；多个网页连接独立选择 |
| 音频授权 | 覆盖令牌隔离、网页所有者与媒体凭据验证、媒体失效、重建后更新凭据、撤销清理；此处是服务级测试，不代表真实双向音频已验证 |
| 进度与取消 | SDK 收到真实 progress 通知；客户端取消传递至服务端业务上下文，不重复执行；业务错误和发送进度失败不会转成成功 |
| 录音与设备标识 | 实际读取测试文件内容；拒绝路径穿越和撤销后的读取；移除录音产物的服务器路径，返回资源引用；保留设备发现及配置所需的 USB、控制端口、QMI 路径 |
| 网页静态检查 | 392 项前端测试、类型检查、受影响文件 ESLint、生产构建通过 |
| 客户端接入模板 | Codex、Claude Code、Cursor、Gemini CLI、Hermes、DeepSeek dsh、Pi、Grok Build 的配置契约、特殊字符转义、令牌占位符与复制说明通过测试；八种生成内容分别经 JSON、Go TOML/YAML 解析器验证语法；除下面记录的 Grok Build 外，其余原生客户端未逐一连接验收 |

| 客户端组件浏览器检查 | 实际 Vue 组件的七种客户端逐项切换、配置预览和「复制给 Agent」剪贴板内容通过；键盘可选择 DeepSeek dsh；375px 视口页面宽度与内容宽度一致，无横向溢出。组件独立挂载验证，未绕过部署网页的登录流程 |
| 完整设置页布局 | `mcp-00e181ca` 在 179 的已登录完整设置页验证：修复 MCP 落入 360px 窄列的问题，区块横跨整个设置栅格，桌面实测与设置区同宽 1438px；1024px、375px 和 812px 横屏下区块与父级同宽，页面及 MCP 内容均无横向溢出；七个 Agent 选项及 DeepSeek dsh 配置预览正常 |
| 网页音频生命周期 | 7 项新增回归覆盖媒体重建、解除绑定与异步响应交错、页面缓存恢复、离页时未完成的授权、真实错误传播；不依赖真实麦克风，不能替代真机验收 |
| 网页浏览器检查 | 使用实际 MCP 设置组件和隔离 SQLite 管理接口，检查桌面与 375px 布局、令牌元数据展示、开关初始状态、空名称禁止创建、键盘展开连接配置；未在浏览器中授予真实令牌或麦克风权限 |

后端检查命令如下。所有测试命令同时使用 60 秒进程硬超时和 Go 的 `-timeout=60s`；编译单独限时。未列入全仓库测试。

```sh
go test -timeout=60s ./internal/api ./internal/mcpserver ./internal/db ./internal/config ./internal/phone ./internal/commandcenter ./internal/automation ./internal/mbn
go test -race -timeout=60s ./internal/api ./internal/mcpserver ./internal/config ./internal/phone ./internal/commandcenter ./internal/automation ./internal/mbn
go test -race -timeout=60s ./internal/db
go test -timeout=60s ./internal/device -run 'MBN|Outbound|RoutedSMS|OperatorSelection|ManagedDeviceMutation|ESIMSwitch' -count=1
go vet ./internal/api ./internal/mcpserver ./internal/db ./internal/config ./internal/phone ./internal/mbn
go build ./cmd/hideck
```

数据库 race 作为独立包通过。初次 race 构建超过进程硬时限，先单独编译后执行；直接执行 API 测试二进制时必须在 `internal/api` 目录运行，以解析原有 OpenAPI 测试文件。

输出契约与诊断改动执行 API/MCP 模块单元测试、分包 race 和 vet，测试进程和 Go 测试均保持 60 秒硬时限。合并编译和执行 race 曾触及进程硬时限；最终将 API race 编译与执行分开，完整 API race 执行 42.61 秒通过，MCP 模块 race 与 vet 通过。前端 392 项测试、受影响文件 ESLint、类型检查和生产构建通过。硬件写操作及真实音频验收仍保持下表待执行状态。

MBN 的两项原有成功驻网测试出现轮询与截止时间重合的失败。仅将这些成功场景的测试注册窗口从一秒改为两秒，稳定期和成功断言保持不变，复验通过；没有修改生产 MBN 超时或重试策略。前端构建保留现有大于 500 kB 的包体积提示。

## 179 测试机部署验证

已部署 `mcp-85a615e7`。部署前确认无活跃通话，备份配置、systemd 服务与 SQLite 数据，保留旧二进制；上传文件经 SHA-256 校验后切换服务，服务运行且无自动重启。

使用官方 SDK 连接部署实例，发现 125 个工具，实际执行设备、联系人、电话、命令、自动任务、运营商规则、代理及诊断等 13 项查询，并读取录音资源。验证跨源拒绝、网页/MCP 鉴权隔离、开关实时生效、撤销后拒绝，以及未绑定网页音频时拒绝操作；临时测试令牌已撤销。此次健康接口返回 HTTP 200，两台模组 `modem_ok` 为真，网络连接均为假；没有实际发送短信、外呼或修改 eSIM。

HTTPS 使用部署实例的本地 CA 验证证书，未关闭证书校验；首页与设置页 JavaScript 的部署内容匹配本地产物。七种原生客户端的逐一连接测试仍未执行。

令牌删除功能部署为 `mcp-b7b38ea7` 后，实际创建并删除有效及已撤销临时令牌：记录从列表移除，旧令牌访问返回 401，重复删除返回 404；MCP 令牌及未登录请求不能调用删除接口，已有记录保持不变。网页检查删除按钮、确认提示和取消后保留记录；375px 下令牌列表及页面均无横向溢出。相关后端测试、API/MCP 与数据库分开执行的 race、vet、391 项前端测试及构建通过；首次批量 race 触及 60 秒硬时限后拆包复验通过。

创建表单改进部署为 `mcp-44afb373`：复现旧页面空名称禁用按钮、填写名称后启用。新版明确标注名称必填；空名称点击及纯空格按 Enter 都显示字段错误并聚焦名称框，输入后清除错误。实际页面及 375px 表单无横向溢出，验证期间未创建真实令牌。391 项前端测试、受影响文件 ESLint、类型检查与构建通过；此次没有修改后端业务逻辑。

Grok Build 与精简文案部署为 `mcp-51c998bc`：部署前无活跃通话，配置、systemd 与 SQLite 已备份，旧二进制保留。Linux 构建及压缩产物完整性检查通过，上传 SHA-256 一致，服务运行且无自动重启。179 完整设置页展示八个客户端，Grok Build 使用 `headers` 的 TOML 预览、配置路径和「复制给 Agent」内容正确；桌面 MCP 区块与设置区同宽 1438px，375px 下页面与区块无横向溢出，空名称错误与聚焦正常。HTTPS 首页及设置页脚本哈希匹配本地产物，未鉴权 MCP 返回 401；部署后 Grok Build 原生 HTTPS 诊断再次通过，发现 125 个工具，临时令牌记录已删除。392 项前端测试、受影响文件 ESLint、类型检查与构建通过；本次没有修改后端业务逻辑，未重复运行后端单元测试。
